# 木叶手帖 · Naruto Journey

一本中文《火影忍者》观剧手帖，整理动画第 **1–10 集**的人物、关系、地域与故事线。随着观看进度继续补充，尽量避免提前透露后续剧情。

## 功能

- **按集数浏览**：查看每集的剧情重点、主要人物及关系变化。
- **人物档案**：搜索人物，并按立场和主线／支线筛选；点击卡片查看详情。
- **人物关系**：整理师生、队友、亲属、雇佣与敌对关系。
- **地域图鉴**：区分人物的出身、所属与当前活动地。
- **故事线**：追踪第七班成长、波之国任务及人物支线。

人物标记：

| 标记 | 含义 |
| --- | --- |
| ⭐ | 常驻／主线人物 |
| 📌 | 单支线人物 |
| 正派 | 当前阶段偏向主角一方 |
| 反派 | 当前阶段与主角一方对立 |
| 立场复杂／TBD | 动机或立场尚待观察 |

这些分类是截至第 10 集的观剧整理，不代表角色的最终立场。

## 本地打开

下载 `index.html`，用浏览器打开即可。不需要安装依赖或运行构建命令。

网站使用原生 HTML、CSS 和 JavaScript，支持桌面与手机屏幕。

## 文件结构

将网站文件放在仓库根目录：

```text
naruto-journey/
├── index.html     # 页面、样式、交互和档案数据
└── README.md      # 项目说明
```

## 发布到 Netlify

1. 将 `index.html` 上传到 GitHub 仓库并提交。
2. 登录 Netlify，选择 **Add new project → Import an existing project**。
3. 连接 GitHub，选择本仓库。
4. 使用以下配置：

| 配置 | 值 |
| --- | --- |
| Branch to deploy | `main`（如果使用其他默认分支，选择对应分支） |
| Base directory | 留空 |
| Build command | 留空 |
| Publish directory | `.` |

5. 发布成功后，使用 Netlify 提供的正式网站网址分享给朋友。

以上配置适用于 `index.html` 位于仓库根目录的情况。

## 更新网站

1. 修改 `index.html`。
2. 将新版文件提交到同一个 GitHub 仓库的部署分支。
3. Netlify 会自动触发部署。
4. 部署成功后，访问者刷新原来的网址即可看到更新。

**只修改电脑上的文件不会自动发布；需要先提交到 GitHub。** 更新现有网站时无需创建新项目，也无需重新分享网址。

## 维护内容

人物数据保存在 `index.html` 中的 `people` 数组，分集内容保存在 `eps` 数组；人物关系、地域与故事线在 `render()` 函数对应的区块中维护。

扩展观看范围时，请同步检查页面上的进度标记、集数按钮和说明文字。当前部分界面以第 10 集为固定范围，新增数据后也需要调整这些显示。

## 资料与说明

- 分集核对参考：[NARUTO 官方动画目录](https://naruto-official.com/en/anime/naruto1/list)。外部页面可能包含后续剧情链接。
- 中文标题为手帖整理用的意译，不保证与各播放平台译名一致。
- 每集人物列表为重点人物整理，并非逐镜头的完整出场名单。
- 当前集数页面的人物详情统一按截至第 10 集的信息展示；查看较早集数时，详情可能包含之后几集的信息。
